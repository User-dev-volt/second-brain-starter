# Idea Capture

Zero-friction idea capture. Appends to the backlog with context so ideas don't vanish.

## Parameters

- **`$0`** (required) — The idea text. Can be brief or detailed.
- `--project` (optional) — The source project this idea came from (e.g., `moviebuilder`, `Project_Chimera`)
- `--category` (optional) — Defaults to auto-detected from context. Options: `game-mechanic`, `product`, `business`, `feature`, `other`

## Workflow

1. **Parse the idea** — Extract the idea text from `$0`. If no text is provided, ask: "What's the idea?"

2. **Infer context if not provided:**
   - Check the current working directory to guess the source project (use vault_router logic: game dev dirs → game-mechanic, product dirs → product)
   - If CWD doesn't help, leave `source_project` blank

3. **Capture the idea** — Run:
   ```
   python .claude/scripts/query.py obsidian idea "<idea text>" --project "<project>"
   ```

4. **Confirm in one line:** `Captured → [backlog](D:\Brain\00_Meta\ideas\_backlog.md)`

## Format Written to Backlog

```markdown
## [2026-04-08 14:32] <Category> — <First 8 words of idea...>
**Source project:** <project or "unattributed">
**Category:** <category>
**Idea:** <full idea text>
**Surface when:** <auto-generated hint based on category>
```

## Surface When Hints (auto-generated)

| Category | Surface when |
|----------|-------------|
| game-mechanic | working on game systems, enemy AI, or world-building |
| product | reviewing the product roadmap or planning features |
| business | evaluating business model or monetization strategy |
| feature | planning the next sprint for the relevant project |
| other | doing a weekly review |
